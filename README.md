# note Amazon Affiliate Writer

note向けAmazonアフィリエイト記事制作ルールの正本です。

## ファイル
- `SKILL.md`：制作工程、Amazonリンク、完成条件
- `references/`：調査・執筆・監査・運用・納品の詳細ルール
- `distribution/note-amazon-affiliate-writer/`：初回配布するGitHub参照版の入口

## 配布後の更新
利用者は入口を初回にインストールします。以後、制作前にmainの現在のコミットSHAを確定し、そのSHAの制作ルールを取得します。管理者が直下のSKILL.mdやreferencesを更新すると、次の実行から新ルールを使用します。制作途中で版を切り替えません。

既存の固定版スキルを使っている利用者には、初回のみ入口版への入れ替えが必要です。入口の取得先や方式自体を変える場合は再配布が必要になることがあります。

## 現在のアクセス条件
このリポジトリは非公開で作成しています。GitHub参照版を使う利用者は、自分のGitHub連携とこのリポジトリの閲覧権限が必要です。管理者のGitHub連携や認証情報は配布しません。
認証なしの配布を行う場合は、公開する制作ルールの範囲と配信方法を別途決定してください。

## 更新時の確認
1. mainのSKILL.mdまたはreferencesを編集する。
2. 事実確認、仕様の矛盾、リンク規則を点検する。
3. 制作ルールの版を更新する。
4. 入口から同じSHAの必須6資料を取得できることを確認する。

初回登録：制作ルール2.1.0。初稿から確認済みAmazon実URLを設置し、本人のアソシエイトURL未提供時は通常商品URLを使用します。
