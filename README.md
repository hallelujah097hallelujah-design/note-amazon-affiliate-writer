# note Amazon Affiliate Writer

note向けAmazonアフィリエイト記事制作ルールの正本と、公開URLから最新版を取得する配布用スキルです。

## 公開される範囲
このリポジトリ内の制作ルール・参照資料・配布用ファイルと変更履歴を公開する構成です。生徒の原稿、個人情報、認証情報を保存しないでください。

## 生徒向け配布
`distribution/note-amazon-affiliate-writer/`をZIP化したものを一度インストールします。公開後はGitHubアカウント・GitHub連携・個別招待は不要です。Python 3と外部HTTPS取得が可能な実行環境が必要です。
固定版または旧GitHub連携版を配布済みの場合、最初の1回だけこの公開URL版へ入れ替えてください。リポジトリ全体のSource code ZIPではなく、distribution内のスキルフォルダを配布します。

## 配布後の更新
- 正本：直下の`SKILL.md`と`references/`の5資料。
- 制作前に公開GitHub APIでmainのコミットSHAを確定し、そのSHAの6資料を公開URLから認証なしで取得します。
- mainの正本を更新すると、次の実行から新ルールを取得します。作業中の記事では版を混ぜません。
- 取得制限・404・タイムアウト・必須資料不足の場合は、旧版で続行しません。
- 入口のURL・取得方式・必須ファイル構成を変更した場合は、ZIP再配布が必要になることがあります。
- 公開設定と匿名取得を確認済みです（2026年10月28日、制作ルールv2.1.0、必須6資料）。

## 管理者の更新手順
1. 直下のSKILL.mdとreferencesを編集し、制作ルールのversionを更新する。
2. 内容・整合性を確認してmainへ保存する。
3. 配布用scripts/fetch_rules.pyを認証なしで実行し、変更後の版・SHA・6資料を取得できることを確認する。
4. 入口も変更した場合はdistributionとインストール済み入口を揃える。

## 初回の制作ルール
v2.1.0。初稿から確認済みのAmazon実URLを設置します。本人のアソシエイトURL未提供時は通常商品URLを使用します。通常URLで本人の紹介料が得られるとは説明しません。
